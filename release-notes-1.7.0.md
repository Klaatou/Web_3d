Already have one of these packages? Do not unzip over your folder: it would overwrite your config, zones and images. See docs/en/SIMPLE_PROCEDURES.md section 10.

**Release** 1.7.0. New: a small "Made with Web_3d" icon (the Web_3d logo) at the bottom right of the page and of the map, with a bubble linking to the repository; the logo is also the default tab icon (sample `favicon.ico` replaced); animated GIFs on image zones (the page decodes the GIF itself, animates only the planes you can see, and keeps the first frame when the system asks for less motion); the Status window shows "Version: page … · configuration …" and "Copy diagnostics" gives an "Animated GIFs" line; the packages' image zones now use targets without extension, so any image type (jpg, png, gif…) can be dropped in `medias/` under the same number; `carte.html` is published with the site; `extraire_batiments.py` (one GLB per object group of an OAR) and `iar2oar.py` (OpenSim inventory archive to a minimal OAR) join the repository, with French and English messages, `--lang`, English option names (the old French names are still accepted); documentation: `INDEX.md`, the JSON reference as a separate document, the procedure to update a package that is already published, `REFERENCE_OPTIONS.md` regenerated.

**Upgrading a package**: copy `index.html` and `carte.html` from the new zip (and `favicon.ico` if you have not placed your own); do not unzip over your folder.

Reported by a tester: the macOS launcher and the region display work on macOS Ventura 13.7.8 with Firefox 159.0.1. Not tried: Safari, Firefox on Windows, GIF animation outside Chromium.
