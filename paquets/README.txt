PAQUETS : CE DOSSIER CONTIENT LES SOURCES, PAS DES PAQUETS UTILISABLES
======================================================================

FRANCAIS
Ce dossier (paquets/) contient les sources des deux paquets prets a l'emploi. Il n'est pas utilisable tel quel : il manque
site/index.html et site/lib/, que le script fabriquer_paquets.py ajoute en fabriquant les zips.
Si vous avez telecharge le depot par "Code > Download ZIP" et que le lanceur affiche une erreur ou une page introuvable (404),
c'est normal. Telechargez plutot region-simple.zip ou galerie-photos.zip sur la page des versions :
  https://github.com/Klaatou/Web_3d/releases/latest

ENGLISH
This folder (paquets/) holds the sources of the two ready-to-use packages. It cannot be used as it is: site/index.html and site/lib/
are missing, and the fabriquer_paquets.py script adds them when it builds the zips.
If you downloaded the repository with "Code > Download ZIP" and the launcher shows an error or a page not found (404), that is expected.
Download region-simple.zip or galerie-photos.zip from the releases page instead:
  https://github.com/Klaatou/Web_3d/releases/latest
