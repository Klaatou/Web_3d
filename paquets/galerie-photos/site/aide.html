Aide : visiter la galerieHelp: visiting the gallery

Pour le créateur : la documentation de ce paquet est dans galerie.html. Cette page-ci est l'aide des visiteurs : modifiez-la comme vous voulez, et supprimez ce cadre (la balise div d'id="doc-createur") quand elle est prête.

Voici comment visiter la galerie. Les mêmes touches sont rappelées dans la page par la touche H.

À l'ouverture : la vue globale

  • glisser : tourner
  • molette : zoom
  • clic droit + glisser : déplacer
  • R : centrer sur l'arrivée
  • bouton « Recentrer la vue » : cadrage d'ouverture

Entrer en promenade

  • P ou F : entrer
  • double-clic : choisir le point d'atterrissage
  • P ou F : quitter la promenade

Se déplacer

  • ZQSD / flèches (WASD sur un clavier QWERTY)
  • Maj ou double appui Z S ↑ ↓ : courir (W, S sur un clavier QWERTY)
  • Espace : sauter
  • double-clic : se téléporter
  • R : retour à l'arrivée

Voler

  • Début : voler / atterrir (ou le bouton)
  • Page Haut ou Espace maintenu : monter
  • Page Haut maintenu au sol : décoller
  • Page Bas ou C : descendre

Changer de vue

  • V : changer de vue
  • M : subjective / 3e personne
  • molette : distance de la caméra (3e personne) ou zoom (caméra libre)
  • Fin ou Alt + clic : caméra derrière l'avatar
  • Alt + glisser : orbiter

La souris

  • G ou bouton « Capturer la souris », puis souris : regarder (ou glisser, bouton enfoncé)
  • Échap : libérer
  • G : capturer / libérer

Les zones (panneaux, images, portails)

  • clic ou E : panneaux et portails
  • T : repères de portail
  • clic : nom de l'élément

Boutons et menus

  • Promenade (P) : entre en promenade.
  • Retour à l'arrivée (R) : ramène au point d'arrivée.
  • Aide (H) : affiche ou masque l'aide courte de la page.
  • Flèches (K) : affiche ou masque les boutons fléchés au bas de l'écran (déplacer, tourner, zoomer à la souris ou au doigt).
  • Réglages (bouton en haut à droite, ou touche O) : Haute résolution (plus net, plus lourd) ; Rendu léger ; Afficher la mer ; Mer animée ; Vagues ; Choisir la couleur de mon avatar ; Boussole (cap en haut de l'écran) ; Numéros des zones image (repérage) ; Sons ; Disposition du clavier ; Flèches à l'écran (K) ; Commandes tactiles ; Langue / Language ; Valeurs d'origine. Certains réglages n'apparaissent que si la région a des zones image ou la présence. En promenade, Échap libère la souris pour utiliser ce panneau. Tes choix sont mémorisés sur cet appareil.
  • Informations / État (touche I) : la vue, le mode, la position. Son bouton « Copier le diagnostic » aide à signaler un problème.

Voir les autres visiteurs et tchatter (si la présence est activée)

Seulement si le créateur a activé la présence : on y voit les autres visiteurs en promenade et on peut leur écrire.

  • Entrée : écrire
  • Échap : fermer
  • flèches : dans le texte (après Échap : se déplacer)
For the creator: this package's documentation is in galerie.html. This page is the visitors' help: change it as you like, and delete this box (the div tag with id="doc-createur") when it is ready.

Here is how to visit the gallery. The same keys are shown in the page with the H key.

On opening: the global view

  • drag: rotate
  • wheel: zoom
  • right-click + drag: pan
  • R: center on the arrival point
  • "Recenter the view" button: opening framing

Start walking

  • P or F: enter
  • double-click: choose the landing point
  • P or F: leave the walk

Moving around

  • ZQSD / arrows (WASD on a QWERTY keyboard)
  • Shift or double-tap Z S ↑ ↓: run (W, S on a QWERTY keyboard)
  • Space: jump
  • double-click: teleport
  • R: back to the arrival point

Flying

  • Home: fly / land (or the button)
  • Page Up or Space held: go up
  • Page Up held on the ground: take off
  • Page Down or C: go down

Changing the view

  • V: change view
  • M: first / third person
  • wheel: camera distance (third person) or zoom (free camera)
  • End or Alt + click: camera behind the avatar
  • Alt + drag: orbit

The mouse

  • G or the “Capture the mouse” button, then mouse: look around (or drag with the button held)
  • Esc: release
  • G: capture / release

Zones (signs, pictures, portals)

  • click or E: signs and portals
  • T: portal markers
  • click: name of the element

Buttons and menus

  • Walk (P): starts walking.
  • Back to the arrival point (R): takes you back to the arrival point.
  • Help (H): shows or hides the page's short help.
  • Arrows (K): shows or hides the arrow buttons at the bottom of the screen (move, turn, zoom with the mouse or a finger).
  • Settings (button at the top right, or the O key): High resolution (sharper, heavier); Light rendering; Show the sea; Animated sea; Waves; Choose my avatar's color; Compass (heading at the top of the screen); Image zone numbers (to find them); Sounds; Keyboard layout; On-screen arrows (K); Touch controls; Language / Langue; Default values. Some settings only appear if the region has image zones or presence. While walking, Esc releases the mouse so you can use this panel. Your choices are remembered on this device.
  • Information / Status (I key): the view, the mode, the position. Its “Copy diagnostics” button helps to report a problem.

Seeing the other visitors and chatting (if presence is on)

Only if the creator turned presence on: you can see the other visitors who are walking and write to them.

  • Enter: write
  • Esc: close
  • arrows: in the text (after Esc: move around)
